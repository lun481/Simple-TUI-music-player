# Music files

Put your audio files here (`.mp3`, `.flac`, `.wav`, `.ogg`, `.oga`), or pass
another directory/file to the player:

```powershell
.\build\bin\Release\music-player.exe D:\Music
.\build\bin\Release\music-player.exe D:\Music -r
```

This folder is intentionally empty; audio files are ignored by `.gitignore`.
